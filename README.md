# 📋 Kanban Task Manager

A simple yet powerful Kanban Task Manager built with **HTML**, **CSS**, and **Vanilla JavaScript**. Organize your tasks efficiently with a drag-and-drop interface and persistent local storage.

## ✨ Features

- ✅ **Create & Delete Tasks** - Easily add new tasks or remove completed ones
- 🎯 **Drag & Drop** - Intuitive drag-and-drop interface for moving tasks between columns
- 📊 **Three-Column Workflow** - Organize tasks into To Do, In Progress, and Done
- 🔢 **Task Count Tracking** - Real-time counter for tasks in each column
- 💾 **LocalStorage Persistence** - Your tasks are automatically saved and persist across sessions
- 📱 **Responsive Design** - Clean, responsive layout with text wrapping support

## 🚀 Getting Started

### Prerequisites
No dependencies required! This project uses vanilla JavaScript and modern CSS.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/IsBroken/Kanban-Board.git
cd Kanban-Board
```

2. Open `index.html` in your web browser or use a live server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

3. Start managing your tasks! 🎉

## 📖 How to Use

1. **Add a Task** - Type your task in the input field and click "Add Task" or press Enter
2. **Move Tasks** - Drag tasks between the To Do, In Progress, and Done columns
3. **Delete a Task** - Click the delete button (usually an X or trash icon) on a task
4. **Track Progress** - Monitor task counts in real-time as you organize your workflow
